# Higher-Ed Retention Dashboard Demo

Synthetic-data dashboard demo for explaining retention-risk model outputs to higher-education stakeholders.

This project is designed as a public portfolio artifact. It does not use university data, student records, or confidential institutional information.

## Purpose

The demo shows how a retention prediction output can be translated into dashboards for:

- executive review
- college/segment planning
- advisor worklist design
- model QA and threshold discussion
- data governance conversations

## Planned Dashboard Pages

| Page | Purpose |
| --- | --- |
| Executive Overview | Shows cohort size, predicted retention, risk volume, and key model context |
| College And Segment View | Shows where support demand may concentrate by college or student segment |
| Academic Progress Drivers | Explains how course load, pass rate, failures, and withdrawals relate to risk |
| Advisor Worklist Concept | Shows how a restricted student-review page could be structured |
| Technical Model QA | Shows model comparison, temporal validation, and precision/recall tradeoffs |

## Data Design

The project will use synthetic fields modeled after common higher-education reporting patterns:

- cohort year
- college
- credit hours
- pass rate
- failures and withdrawals
- predicted retention probability
- risk category
- capacity group
